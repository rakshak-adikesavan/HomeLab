# Tailscale Docker

Run Tailscale using Docker with a simple YAML configuration.

## 🚀 Features
- Tailscale in Docker
- YAML-based configuration
- Easy setup and deployment
- Secure remote access
- Works with Docker Compose
### Subnet Routing

Subnet routing has also been added to the script, allowing devices connected to Tailscale to securely access services and devices on the local network through the Docker-based Tailscale node.


## ▶️ Usage
1. Configure `docker-compose.yml`.
2. Add your Tailscale authentication settings.
3. Run:
   `docker compose up -d`
4. Check the Tailscale connection and access your service.
