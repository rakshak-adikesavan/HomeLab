# Syncthing on Windows

[Syncthing](https://syncthing.net/) is an open-source, peer-to-peer file synchronization tool that keeps files synchronized between devices without relying on a central cloud server.

## Features

- Peer-to-peer synchronization
- End-to-end encrypted connections
- Automatic file synchronization
- Cross-platform support
- Web-based management interface
- No third-party cloud storage required

## Windows App Service

I found a way to deploy **Syncthing as an App Service in Windows**, allowing it to run automatically in the background without requiring a user to manually start the application.

This makes Syncthing a great fit for:

- Windows servers
- Home labs
- File servers
- Always-on PCs
- Automated file synchronization

The goal of this repository is to document the setup and deployment process.
