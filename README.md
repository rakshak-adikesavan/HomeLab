# Home Lab

A collection of self-hosted services running in my home lab, focused on privacy, local control, file synchronization, photo management, and secure remote access.

## Services

- **Immich** - Self-hosted photo and video management
- **Pi-hole** - Network-wide DNS filtering and ad blocking
- **Syncthing** - Peer-to-peer file synchronization
- **Tailscale** - Secure private networking and remote access

## Overview

This repository documents my home lab services, deployments, configurations, and setup notes.

The goal is to keep commonly used services self-hosted while maintaining simple, reliable, and secure access from anywhere.
